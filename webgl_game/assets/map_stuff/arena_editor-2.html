How to use

1. Load image. Choose Grid corners and drag the 4 handles so the grid lines run parallel to the floor tile seams (handles can sit outside the floor/image). Order: top, right, bottom, left.
1b. Non-rectangular arena: set outline corners (or click Hex / Octagon). Orange handles A, B, C… appear in the Grid corners tool: drag them to trace the arena edge. Double-click an edge to add a corner, double-click a corner to remove it. The grid is drawn only inside the outline, tiles outside are blocked, and the inside is walkable automatically (untick the option to draw walkable areas yourself).
2. Walkable area: click each corner point of the arena. Enter / double-click / click the first point to close. Add as many polygons as you like.
3. Obstacle: polygons cut out of the walkable area (reactor, pillars, consoles).
4. Occluder: trace the part of an object that should hide / fade when someone walks behind it.
5. Export the JSON + occluder PNGs into your game folder.

Select tool: drag points, double-click a point to delete, double-click an edge to add a point, Del removes the shape. Ctrl+Z undo. Wheel = zoom, Space/middle-drag = pan.
