# Light-Wars Sprite Assets

Place your sprite image files in this directory (`assets/sprites/`).

### Expected / Supported Sprite Identifiers:
- `player.png` - Player hero character sprite (aims and rotates toward reticle)
- `enemy_red.png` - Red enemy sprite (band: Cyan)
- `enemy_green.png` - Green enemy sprite (band: Magenta)
- `enemy_blue.png` - Blue enemy sprite (band: Yellow)
- `enemy_cyan.png` - Cyan enemy sprite (band: Red)
- `enemy_magenta.png` - Magenta enemy sprite (band: Green)
- `enemy_yellow.png` - Yellow enemy sprite (band: Blue)
- `orb_red.png`, `orb_green.png`, `orb_blue.png` - Floating orbs
- `white_light.png` - White Light spawn pad rune texture

### Fallback
The engine automatically falls back to procedural 2.5D Brawl-Stars vector rendering if a sprite is not provided or still loading.
